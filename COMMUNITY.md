# Community and launch plan / Развитие сообщества

NDZE welcomes genuine feedback from Windows gamers, iOS users and developers. This is a proposed outreach plan, not a claim of existing users or downloads.

## Try the project

Check [Releases](https://github.com/ndzeone/ndze-launcher/releases) for available builds and [README](README.md) for setup and limitations. Use a test environment for early Windows builds that modify system settings.

Report feedback in [Issues](https://github.com/ndzeone/ndze-launcher/issues): platform, version, what worked, what failed and improvement ideas. Remove private information from logs. Security concerns should follow [SECURITY.md](SECURITY.md).

## Suggested announcement (English)

NDZE is an early-stage MIT-licensed project featuring a Windows 11 game launcher and an iOS client for custom AI APIs. I'm looking for testers and contributors to help improve usability, reliability and documentation. If this sounds useful, check the repository and share honest feedback: https://github.com/ndzeone/ndze-launcher

## Текст для публикации

Разрабатываю NDZE — игровой лаунчер для Windows 11 и iOS-клиент для собственных ИИ-сервисов. Проект на ранней стадии, ищу тестировщиков и разработчиков. Буду рад реальным отзывам, предложениям и сообщениям об ошибках. Исходный код и инструкции: https://github.com/ndzeone/ndze-launcher

## Outreach checklist

- Verify installable builds and publish clear release notes.
- Add actual screenshots or a short demo.
- Share announcements in relevant communities where self-promotion is permitted.
- Respond to feedback and document known issues.
- Track actual downloads, issues and contributions without artificially inflating metrics.
