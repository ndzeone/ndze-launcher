# Security policy / Политика безопасности

NDZE is in early development. Please use the latest available release or report issues against the current default branch. Older versions do not have a guaranteed support period.

## Reporting vulnerabilities

Use [GitHub private vulnerability reporting](https://github.com/ndzeone/ndze-launcher/security/advisories/new) if available. If it is unavailable, open a public issue requesting a private contact channel without disclosing vulnerability details. Never post credentials, exploit details or personal data in public issues.

Include affected component and version or commit, operating system, reproduction steps, expected and actual behavior, potential impact and sanitized logs. Test only on systems and accounts you own or have permission to test.

Priority areas include Windows privilege elevation, registry and power-plan changes, process termination, update integrity, dependency security, iOS Keychain and API credential handling, and custom endpoint request processing.

The maintainer will review reports as availability permits. No fixed response time or bounty is promised. Coordinate disclosure after remediation.

## На русском

Сообщайте об уязвимостях через приватные GitHub Security Advisories, если функция доступна. Иначе запросите приватный канал связи в Issues без раскрытия деталей. Укажите версию, компонент, ОС, шаги воспроизведения и возможный ущерб. Не публикуйте API-ключи, токены, персональные данные и эксплуатационный код. Проверяйте только свои системы или системы с разрешением владельца. Срок ответа и денежное вознаграждение не гарантируются.
